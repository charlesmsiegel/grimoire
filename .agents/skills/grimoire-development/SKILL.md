# Developing Grimoire

Read the repository's [universal instructions](../../../AGENTS.md) first.
Choose the branch below for the files and behavior you are changing. Its index
routes to focused pages: read those that apply before editing, and follow their
links to source owners. Do not load every reference for every task.

| Task | Start here |
|---|---|
| Record editors, navigation or keyboard shortcuts | [Frontend](references/frontend/index.md) |
| Store writes, caches, runs, records, prompts or observability | [Backend](references/backend/index.md) |
| LLM calls, decisions, embeddings, settings or costs | [Inference](references/inference/index.md) |
| Test fixtures, coverage, templates or verification | [Testing](references/testing/index.md) |
| Android, dependencies or packaged filesystem access | [Packaging](references/android/packaging.md) |

For a change spanning areas, follow each relevant branch. Detailed rules remain
authoritative in their linked owner; this entry point is a route, not a second copy.
