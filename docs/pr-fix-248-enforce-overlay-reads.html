Enforce that campaign reads of inheritable records go through store/overlay.py (#248)

What this change actually does

It adds a static guard, not a behavior change. A campaign inherits records from its world and materializes them only on divergence, so reading an inheritable record straight off campaigns.campaign_root(cid) silently misses everything still inherited and every tombstone in the campaign's deleted.json. Nothing enforced that reads go through backend/src/grimoire/store/overlay.py. This diff declares the inheritance surface as data, adds a CI tripwire over it, and renames the ~20 pre-existing campaign-side actor reads so each one states the invariant it was already relying on.

Every one of those reads was already correct. The value delivered is legibility and enforcement: the next croot-only read fails a test instead of shipping.

The rule the guard encodes

Reading a campaign-scoped record has three legitimate shapes and one mistake. The guard's job is to tell them apart statically.

flowchart TD
  A["caller needs a record
under a campaign"] --> B{"is the kind in
overlay.INHERITED_KINDS
or INHERITED_FILES?"}
  B -- "no (scenes, sheets, climate.json,
appearances.json, dossier.md)" --> L["campaigns.campaign_root(cid)
read it directly"]
  B -- yes --> C{"is this a read?"}
  C -- "no, a write" --> W["campaigns.campaign_root(cid)
the write IS materialization"]
  C -- yes --> D{"do I already know
it is materialized?"}
  D -- "yes — it is in the
appearance record" --> K["appearances.locked_actor_root(cid)
the lock copied it in"]
  D -- no --> O["store.overlay.*
campaign wins, else tombstone,
else the world"]
  D -. "assumed, unstated" .-> X["raw campaign root
= the bug this guard catches"]
  style X fill:#5b1d1d,stroke:#b44,color:#fff
  style O fill:#1d4a2b,stroke:#4b8,color:#fff
  style K fill:#1d3a5b,stroke:#48b,color:#fff

The dotted edge is the whole issue: before this change, the K and X branches were spelled identically at the call site (croot = campaigns.campaign_root(cid)), so a reviewer could not tell which one they were reading. Naming the K branch is what makes X visible.

Invariant impact

  • Strengthened. "Campaign reads of inheritable records go through the overlay" moves from prose in a module docstring to a test. It is now checked on every run rather than at review time.
  • Newly named, not newly created. "An actor in appearances.json has a campaign-side copy at its locked version" already held and was already depended on in six modules.
