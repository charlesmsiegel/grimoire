# Auxiliary Writing and Non-Canonical Variants

**Outcome:** Give players and authors quick ways to brainstorm, polish, translate or try alternative dialogue without confusing suggestions with real scene history.

## Scope
- Support write-as-PC, continue-as-character, hypothetical dialogue, brainstorm, polish and translate as clearly labelled non-canonical outputs.
- Use the smallest adequate acceptance path: copy, replace draft, insert as a reviewed post or discard.
- Preserve original speaker attribution, source text and input history; no variant becomes campaign truth just because it was generated.
- Honor model routing, privacy and context budgets.

## Milestones
1. Offer one draft polishing and one hypothetical-dialogue action without saving a scene.
2. Support reviewed insertion/replacement with visible before/after and correct authorship.
3. Add advanced multilingual/style variants, compare alternatives and player-chosen voice constraints.

## Moonshot
A player can collaboratively edit prose and roleplay performances with a responsive creative partner while every draft, alternate reading and accepted canon boundary remains comprehensible.

## Proving scenario
The user asks how an NPC *might* react to a confession, copies one possible reply, and continues the actual scene unchanged. Only an explicit accept action can insert it as a post.

## Independence and interfaces
Can reuse present composer and generation controls immediately. No universal auxiliary dispatcher, agent framework, voice runtime or new story-state owner is required.

## Open questions
- Which variants genuinely need their own interface?
- Which operations should act on a draft versus a stored post?
- How should context and privacy restrictions differ for hypothetical outputs?
