# System-Specific Action and Resolution Contracts

**Outcome:** Expose the smallest truthful interface across genuinely different games without pretending all are d20 checks.

## Scope
- Research fiction triggers, legal actions, opposed actions, partial successes, costs, clocks, seasons and effects.
- Test D&D, WoD, Ars Magica and PbtA as distinct reference families.
- Permit one selected module or none; authored hybrids are one composite module.

## Milestones
1. Write four concrete action examples and incompatible result shapes.
2. Prove validation and result records through one minimal shared contract.
3. Record capabilities that need module-specific executable hooks rather than false universal fields.

## Proving scenario
A PbtA move triggers from fiction and may yield partial success, while an Ars Magica season spends months; a no-mechanics scene invokes no fake roll.

## Independence and interfaces
A research-and-prototype sprint that can run alongside engineering cleanup and before full mechanical integration.

## Open questions
- What fields genuinely belong in the common envelope?
- Which actions need bounded executable hooks?
- How do edition/version conflicts appear?
