# Roadmap 09-S4: async semantic history retrieval and widening

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax for tracking.

**Goal:** Enhance narrator recall with bounded optional async embeddings and tier-2 widening.
**Architecture:** Resolve one embedding space in a worker, load live document vectors in workers, embed queries plus a rotating bounded warm through the native async door, then save returned document vectors and record materialized rows. History and lore share an in-memory outage memo.
**Tech Stack:** Existing async embeddings client, vector cache, SearchDocuments and anyio workers.
**Spec:** `docs/superpowers/specs/2026-10-09-roadmap-09-hybrid-historical-retrieval-design.md`, 09-S4, sections 6.3, 10–11 and the 2026-10-13 bounds/coverage corrections.

## Global Constraints

- One resolved `embed_space.endpoint()` supplies every load/save/send; queries are never cached. Task `history-recall`, never `history-index`, with campaign, scene, post and run attribution where available.
- One embed call carries query texts plus at most `embeddings.BATCH-len(texts)` missing documents; `queries=len(texts)`. Only `bad_response` with document warm retries query-only once, under the same deadline.
- `POOL_MAX=64` after structural/lexical union; at most `WIDEN_LIMIT=1000` unique documents loaded/scored overall, including tier 1; lexical candidates outside those limits remain retained.
- Exhausted coverage requires available semantic evaluation complete. Old shared-group evidence beyond the pool remains eligible for widening.
- Wrong widths/range violations evict document vectors. Successful returned documents save by space/text and call `searchdocs.embedded.record_embedded`; cancelled retrieval saves nothing after cancellation.
- `OUTAGE_BACKOFF=60` seconds, keyed by space id and shared with lore; auth/network/rate_limit/timeout set it, successful requests clear it. No new error logging beside the production meter.

## Review Focus

- Over 1,064 weighted cast-name matches must not cause unbounded vector reads.
- A group admitting all scenes must not hide old semantic evidence beyond the first 64.
- Query/document request splitting must remain one ledger row per embed call.
- Stalled endpoints must honor the phase deadline and suppress the next history/lore request.
- Cancellation between returned vectors and a worker save must not publish cancelled results.
