# Roadmap 09-S2: history prompt section and inspector

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax for tracking.

**Goal:** Render, fit, shed and inspect frozen historical evidence while preserving off prompts.
**Architecture:** Compose accepts completed `Evidence`; a dedicated context module renders safe item blocks, expands macros once and re-fits frozen strings before packing. Inspector metadata travels alongside text and never enters it.
**Tech Stack:** Python, Jinja, existing generic shed hook; React/TypeScript settings and inspector.
**Spec:** `docs/superpowers/specs/2026-10-09-roadmap-09-hybrid-historical-retrieval-design.md`, 09-S2 and section 9, with the macro-ceiling correction.

## Global Constraints

- All repository privacy/import/Android rules apply. Reuse the placeholder set and isolated stores.
- `HISTORY_RECALL` is first in `DROP_ORDER`, before `RECALLED`; defaults remain depth 0, budget 1200, cosine 0.35, rerank off.
- Off or disabled layout is byte-identical and spends nothing; NPC prompts are blank until 11-C2. Narrator `actor_ref="grimoire"` follows the existing non-actor-scoped branch.
- `SceneRef.key` names shed units; lowest ordered scene sheds first. Fit macro-expanded strings independently of `context_budget`, including zero, and never redraw a macro.
- Summary omission requires enabled archive/full recap already carrying it; a header without excerpt or summary consumes no selected slot. gm-only/excluded locations never appear in headers.

## Review Focus

- Expanding `{{user}}` macros must respect the section ceiling with context budgets zero and positive.
- `{{random}}` must stay fixed after fit and shed.
- Enabling the layout section while depth remains zero must not construct an embedding client or read compiled history.
- A disabled archive must not cause its summary to disappear from recalled history.
- Inspector signal markers must remain absent from the sent prompt.
