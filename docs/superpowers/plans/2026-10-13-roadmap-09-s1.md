# Roadmap 09-S1: structural and lexical retrieval

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax for tracking.

**Goal:** Return bounded, prompt-view historical evidence without network calls.
**Architecture:** Read 08's live documents, derive independent structural and lexical admission, order admitted lists with RRF, then expand and fit selected scenes. Scene keys distinguish legacy scenes; retained candidates are bounded by the live set, independently of later semantic I/O caps.
**Tech Stack:** Python 3.11+, dataclasses, existing compiled cache and SearchDocuments.
**Spec:** `docs/superpowers/specs/2026-10-09-roadmap-09-hybrid-historical-retrieval-design.md`, 09-S1, sections 4–8, 11, 13–15, including the 2026-10-13 corrections.

## Global Constraints

- Privacy: use only Seraphine, Mara, Winifred, Realm, Saltmarch and role labels; every test sets `GRIMOIRE_HOME` to a temporary directory. Never read the real library.
- Pure Python; no new base dependency; module-scope acyclic imports; bind sibling store submodules, never their functions.
- `history_recall_depth=0`, `history_recall_budget=1200`, `history_recall_threshold=0.35`, `history_recall_rerank=off`.
- `SceneRef.key` is identity when present, else `sid:` plus sid. No identity minting or campaign writes/locks.
- Structural admission: `STRUCTURAL_PLAIN_CAP=12`; one weighted lexical term or two plain terms; `RRF_K=60`; only admitted signal lists contribute ranks.
- Excerpts: prompt phase, radius 1, at most 2 excerpts, `fallback="none"`; retain per-post index/key/part/speaker/text. `MIN_ITEM_TOKENS=80`; count the entire rendered section, heading included.

## Review Focus

- Two identity-less scenes must remain distinct through merge and fitting.
- A changed document remains live while its superseded cache row remains unreachable.
- A protected name must be removed as a phrase and as its constituent plain terms.
- More than `POOL_MAX + WIDEN_LIMIT` lexical matches remain available for merging.
- Malformed nested ledgers remove their own signal without failing other signals.

### Task 1: The network-free history package

**Resolved handoffs:** `budget.render(items)` and `budget.render_item(item)`
use the authoritative section/item templates created here. The section
template owns the heading/separators and consumes rendered item blocks; S2
can freeze those blocks and fixed template runs without duplicating text.
`retrieve_preview(..., *, summary_omissions=None)` takes a plain mapping of
scene ids to archive/recap omission reasons, skips summary-only omitted items
before spending depth, and retains original summaries plus omission reasons.
Test depth 1 with an omitted first candidate and a usable next candidate.
`merge`'s `expand` callback returns `EvidenceItem | None` for a `Candidate`,
bound to source/query/metadata/budget by its caller; low-level `expand.excerpts`
still returns excerpt tuples. Test a newly selected, previously unexpanded
candidate's header, summary, posts and evidence ids. The configured depth
comes from settings, never `len(Evidence.items)`. Public `Query.terms` remains
a tuple of strings; scoring receives a private, live-catalog-derived weight
map. A query preparation helper may return the built Query, un-clipped scan
text and private weights so S3 can reuse one read for archive omission.

**Files:** Create `backend/src/grimoire/store/history/{__init__,model,settings,refs,query,structural,lexical,merge,coverage,expand,budget,retrieve}.py`, `templates/scene/sections/history_recall.j2` and `history_item.j2`; modify `store/config.py`, `store/compiled.py`, `store/__init__.py` and the relevant facade/regex guards; create `backend/tests/test_history_core.py`, `test_history_query.py`, `test_history_merge.py` and shared synthetic scaffolding only if more than one suite needs it. The authoritative templates land here because budget fitting must count actual rendered text; S2 registers and consumes them.

**Interfaces:** Frozen models follow 09-C1: `Query`, `SceneRef`, `Relation`, `StructuralSignal`, `LexicalSignal`, `SemanticSignal`, `RerankSignal`, `Signals`, `Candidate`, `EvidencePost`, `Excerpt`, `EvidenceItem`, `Coverage`, `Evidence.detail()`. Export `history.retrieve_preview(cid, sid, query, ceiling) -> Evidence` and `history.merge(a, b, *, ceiling, expand, rerank=None) -> Evidence`. Internal seams: `query.build(cid, sid, *, seed="", actor_ref=None) -> Query`, `refs.norm(ref) -> str`, `coverage.verdict(candidates, depth, eligible, *, semantic_complete=True) -> Coverage`, `expand.excerpts(cid, scene, query, max_bytes) -> tuple[Excerpt, ...]`, `budget.ceiling(cfg, resolved) -> int`, `budget.fit(items, ceiling, count) -> list[EvidenceItem]`.
