## Concrete states the plan must prevent

1. **Unsaved slug reuse:** capture Salt Circle, delete it during generation, recreate byte-identical Salt Circle, then stage/save old output. Minting tokens at stage/save would bless the replacement. Capture must mint against the original before generation; deletion revokes it durably.
2. **A → B → A:** campaign captures inherited Realm group, switches to Saltmarch, Realm deletes/recreates group, campaign returns to Realm. Current-dependent discovery misses its old source claim. The strict barrier-protected historical-source union must invalidate it despite matching ref/token/bytes on return. A retained owned copy needs a trusted receipt, not merely an own file.
3. **Deferred resurrection:** membership write lands, commit crashes before journal/citation publication, group is deleted/recreated, resume publishes old deferred Undo/citation. Fencing only `journal.json` misses `commits.json` pending targets and `journalled` reversals; fence and suppress active publication across all unfinished tokens.
4. **Neutral first copy:** inherited Mara is effective, Winifred filtered; approved Mara leave + Winifred join. Passing batch-wide consent copies Winifred before her receipt; passing no preparation makes Mara's row fail. Neutral baseline removes only Winifred's approved filtered token, then current actor delta lands. Entirely settled rows must make no copy.
5. **Safe ordering:** inherited Mara plus dangling non-detached Winifred, both approved leaves. Winifred remains effectively present until her row; neutralizing her early invents a receipt. Select Winifred's safe cleanup first using canonical deterministic ordering and original-position checkpoints. Two unresolved dangling refs with no single safe delta must refuse all copy-requiring rows. Pending/unconfirmed cleanup cannot count as successful preparation on resume.
6. **Citation/Undo cross-talk:** Winifred payload with `field=members:characters:mara`, or two legitimate actors sharing bare `members`. Validate exact field before reads; derive journal/provenance keys from validated actor, not arbitrary row fields. Otherwise one actor overwrites or forgets another's citation.
7. **Null clears:** provider emits null for optional `knows`, group-state axes or `due`. Model dumping defaults or normalizing null to empty before tolerant staging can clear existing state. Preserve raw omission/null as no update and explicit empty string as the documented clear operation.

## Recommended implementation sequence

Land strict commit parsing and lifecycle/token ownership first; then barrier-aware capture/reservation and progress fences; then schema/prompt/staging; then per-actor writer/Undo with neutral scheduling; finally drawer, eval fixtures and targeted interruption/lifecycle regressions. Existing schema-mode/refusal behavior should be exercised with the shared LLM fakes, and legacy recordings/eval expected-check sets need their specified membership additions. This review ran no tests and is not a substitute for native plan review or the final independent implementation gate.
