# S3 incoming field theory

Sync hashes already cover every frontmatter scalar. Incoming Review now delivers
the declared fields those hashes were hiding, retaining exact stored values while
showing campaign-resolved labels separately. The schema owns declaration order;
union alignment preserves additions and removals on either side.

One fresh View and a local per-kind map decorate only pending reference fields.
Strict captured ledgers and S1 native proofs annotate detached World actors,
without changing authored values or publication/copy authority. The map is never
reused by another campaign. Greeting/card/persona/plot-map shapes retain their
existing owners; no new writer or LLM call exists.

The UI compares raw values, including whitespace, and renders friendly values.
Mine-only fields precede Body. Only Body uses markdown. Exact raw equality can
coexist with different warning text; equal friendly labels cannot hide different
refs. Focused storage/display regressions and existing sync controls substantiate
this model; native/independent gates remain required before completion.
