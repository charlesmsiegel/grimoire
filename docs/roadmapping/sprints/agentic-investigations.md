# Bounded Agentic Investigation and Proposal Jobs

**Outcome:** Use optional multi-step reasoning for tasks that truly need cross-file evidence, not for every ordinary turn.

## Scope
- Define scoped goals, allowed read/propose tools, budgets, trace, cancellation, resumability and reviewable outputs.
- Explore outside file locks, then revalidate sources before any approved write.
- Reuse existing tool calling, run traces, model routing and deterministic Change Set application.

## Milestones
1. Run a read-only consistency audit with attributed findings.
2. Propose an optional multi-file repair for approval.
3. Enable resumable jobs and safe low-risk permissions under explicit user policy.

## Moonshot
A virtual team of bounded research and authoring specialists can maintain an enormous setting, but cannot invent authority or secretly rewrite canon.

## Proving scenario
A worker finds a missing guild link and a possible duplicate, cites evidence for both, and makes no edits when canceled.

## Independence and interfaces
Read-only jobs are independent; integration with World Change Sets is a later optional write path. External scripts/agents remain first-class.

## Open questions
- What job state must survive process restart?
- How is stale evidence detected?
- Which user permissions are revocable?
