# Interactive Maps and Spatial Exploration

**Outcome:** Make locations visible and navigable without requiring a universal geographic coordinate system.

## Scope
- Display location nodes, paths, selection, zoom, annotations and optional custom art.
- Let users place coordinates or use graph auto-layout; preserve authored positions.
- Connect map selection to correct scoped records and scene location, with keyboard/mobile access.

## Milestones
1. Create a readable node-and-edge map for a small setting.
2. Allow manual placement and editing of links with safe scope checks.
3. Add illustrated maps, fog-of-war or layered 2D/3D views when justified.

## Moonshot
A playable, authorable world atlas connects local maps, political boundaries and an evolving campaign footprint without replacing theater-of-the-mind play.

## Proving scenario
A world without coordinates shows its four towns; a blocked road is visibly marked; selecting a similarly named imported site opens the correct record.

## Independence and interfaces
Renders topology if available; can start as a standalone location viewer with current relations. Travel simulation is separate.

## Open questions
- What map coordinate systems are worth supporting?
- How is player-known geography distinguished from GM geography?
- When should paths be editable from the map?
