# Controllable Image Generation for Characters and Scenes

**Outcome:** Create optional coherent backgrounds, portraits and expression variants while protecting user assets and authorship.

## Scope
- Connect selected local/remote image providers with prompts, provenance, privacy and explicit user acceptance.
- Generate art against specified character version, clothing, pose, scene and reference constraints.
- Retain output as ordinary addressable art; costs, failures and cancellations are visible.

## Milestones
1. Generate a reviewed portrait or background without overwriting source assets.
2. Produce a consistent outfit/expression set for a selected character.
3. Support multi-scene visual consistency and author-controlled revisions.

## Moonshot
An art director can maintain a recognizable cinematic cast and location design throughout a hundred-hour campaign.

## Proving scenario
A new generated expression attaches to one character version and survives export; rejecting it changes no campaign state.

## Independence and interfaces
Standalone media job; works with current art manager and does not require voice, 3D or live VN rendering.

## Open questions
- Which providers and rights policies are acceptable?
- How is character consistency measured?
- How are VRAM, cost and decoded-pixel limits enforced?
