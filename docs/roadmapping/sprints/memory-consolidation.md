# Reliable Long-Term Memory Consolidation

**Outcome:** Keep story-relevant facts, promises and history across long campaigns without erasing contradictions or provenance.

## Scope
- Consolidate accepted events into attributable summaries, dossiers and durable references.
- Preserve competing interpretations, corrections and uncertainties.
- Support pruning/compaction that keeps sources available and avoids invented facts.

## Milestones
1. Consolidate several scenes into a useful actor memory.
2. Track a correction and prevent recurrence of the obsolete fact.
3. Scale across thousands of scenes with explicit evidence links.

## Moonshot
Memory remains faithful for campaign-length stories measured in millions of words while retaining an intelligible trail to source evidence.

## Proving scenario
A corrected character identity is never silently overwritten by an older recap; the inspector can show the evidence for each remembered detail.

## Independence and interfaces
Build on existing chronicle, dossiers and wrap-up; audience selection and retrieval are separate contracts.

## Open questions
- Which memories deserve durable structured state?
- How should inconsistent memories coexist?
- When is a summary safe to supersede?
