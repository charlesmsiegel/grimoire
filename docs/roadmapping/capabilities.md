# Capability lookup

**Find a proposed sprint by capability.** Each entry points to a short, future-focused sprint proposal. The main [roadmap](README.md) is organized by practical sequence rather than this thematic inventory.

The labels here describe work **to improve, extend or specify**; they do **not** imply that existing foundation code is absent, and they are not 100+ individually approved implementation sprints. Several related labels belong to the same coherent sprint.
