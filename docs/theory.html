Judge 1

Theory: Grimoire is a local-first, user-owned fiction library in which editable world material and campaign state are canonical, and model output is bounded work that becomes persistent state through explicit application operations. A shared backend and web product serve desktop and Android, with provider-neutral inference, replayable runs and replaceable projections protecting continuity without turning the library into a remote service.

Instead of: A hosted collaborative chat service backed by one relational database is also coherent; the code instead chooses portable user-editable files, local execution and externally chosen providers, accepting single-machine coordination and explicit conflict handling.

Judge 3

Theory: Grimoire is a locally owned world-and-campaign library whose editable records remain authoritative while shared web/native hosts coordinate play, generated suggestions and review. World inheritance and campaign divergence model the content, typed inference requests isolate uncertain external computation, and owned runs separate durable work from transient presentation. Caches, replay fixtures and cost forecasts are supporting representations with deliberately narrower authority than records, model observations and actual accounting.

Instead of: A hosted autonomous game master backed by a central database would be another coherent product, but this repository consistently gives local records, user review and provider-independent operation contracts the authority; Android embeds the same product instead of substituting a second server or native model.
