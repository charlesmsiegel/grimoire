base main @ b5b14cf0 → 7eb0f186 · +4861/−4416 · rebased 2026-07-29

A pure structural split — with one real dispatch regression, caught and fixed inside the branch

backend/src/grimoire/routes.py (4,360 lines, 252 routes) is deleted and replaced by a 13-module routes/ package. Handler bodies are byte-identical: they were sliced by line range, not retyped. The HTTP surface is unchanged — all 256 routes keep the same method, path and handler function.

The one behavioral change is not in any handler: it is in registration order. FastAPI matches in registration order and never backtracks, so splitting one ordered file into ten included routers reshuffles which route wins when two patterns overlap. Commit eb1aca2b flipped the winner on three POST URL shapes; dcb86eb9 restored them by reordering the includes. A residual 405 Allow-header difference (8 of 1,152 probed outcomes) is documented and accepted.
