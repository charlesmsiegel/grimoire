Captured on 2026-10-23 from the completed VN implementation on PR #554.
These are direct, unedited Chromium viewport captures at device scale 1.

| Capture | Viewport |
|---|---|

The isolated library uses synthetic placeholder names and story text from
[the documentation fixture](../../../backend/tests/fixtures/documentation/library.json).
The character sprites and Counting House backdrop were made with the GPT image
generator and stored through the application asset store. They demonstrate sprite
placement, speaker highlighting and background rendering; they are not real
library assets or artwork generated by Grimoire.

The session followed the [isolated capture procedure](../README.md), using fresh
pytest storage, backend port 8209, Vite port 5209 and a fresh browser profile.
The empty library was verified before seeding. Historical checkpoints were
created for the fixture posts. A cassette-backed fake supplied the model
dependency, and provider endpoints were redirected to loopback. No hosted model
calls were made. No DOM replacement, screenshot editing or redaction was used.

The reader occupies the full application viewport; Exit VN returns to play and
restores the application navigation. The reader is on the second post, with
Seraphine speaking. The controls capture
shows per-character outfit, expression and visibility options and the location
background setting. Each image was visually inspected; the browser reported no
page errors or failed requests, and mobile content had no horizontal overflow.
The viewport and exit flow were also checked at 1440 × 900, 390 × 844 and
667 × 375: the reader matched the viewport bounds and exiting restored the app
header. Temporary scripts, browser profiles, stores and logs remain outside the
public tree.
