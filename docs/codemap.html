grimoire

Grimoire is a local library and play application: editable files hold canonical state, domain modules assemble campaign context, and typed inference operations mediate model behavior. One React UI runs in a desktop browser or an Android WebView around the same backend.

The highest-consequence review seams are terminal persistence, cache freshness across asynchronous writes, tool threads that outlive cancellation, and synthetic measurements being read as model-quality evidence.
