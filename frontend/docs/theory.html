Theory: The frontend is a scoped view and editor of the backend's library, keeping record identity, pending user intent and long-running work separate from the current screen or socket. Instead of: Instead of building a second durable application database in the browser, the UI uses keyed ephemeral memory, explicit mutation signals and backend run discovery; the shared React application also supplies Android's product UI.
