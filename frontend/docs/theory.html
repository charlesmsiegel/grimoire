                      The persistent recovery identity lacks the library dimension, so a guard using the current root cannot decide which old entries belong to it. Preserving rather than deleting words requires storing ownership and propagating it through registry/recovery calls.

                      Changing the active storage root and retaining words through navigation/reload are supported workflows.
