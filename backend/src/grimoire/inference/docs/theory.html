Judge 1

Theory: Inference executes a caller-resolved operation: generation sends text, decisions progress through typed answering stages and one escalation hop, and tool runs alternate model turns with caller-owned execution under a shared budget. The layer owns operation policy and attribution while the transport facade owns provider attempts and the caller owns the target library work.

Instead of: Letting every route implement its own retry, fallback, decision parser and tool loop would preserve local flexibility but duplicate accounting and stop rules; this layer centralizes those operation semantics over one facade.

Judge 3

Theory: Inference is an admitted application operation over an already resolved task, with generation, closed decisions and bounded tool runs owning different execution semantics. Decision stages advance only failed items, while post-answer escalation is a separate one-hop policy; every actual request carries attribution and metering. Tool execution is caller-supplied work coordinated under explicit time, count, context and projected-spend limits.

Instead of: A universal agent call with retry and recursion could hide all model interactions, but the code keeps operation admission, failed-call progression, uncertainty escalation and tool execution distinct so one policy cannot silently change another.
