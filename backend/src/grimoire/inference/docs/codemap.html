grimoire-inference

Inference is the application operation layer above the provider facade: generate, decide and bounded tool loops consume already-resolved task policy. It owns operation validation, stage/fallback semantics, per-call metering and tool-loop budgets rather than connection configuration.

Decision chain

sequenceDiagram
  participant A as Resolved task
  participant B as Primary stage
  participant C as Fallback stage
  participant D as Answer assembly
  A->>B: Validate resolved task and operation
  B->>C: Ask primary stage for items
  alt No stage answered an item
    C-->>A: Error or explicitly incomplete result
  else supported path
    C->>D: Pass only failed items to next stage
    D-->>A: Assemble answers, errors and escalation trace
  end
