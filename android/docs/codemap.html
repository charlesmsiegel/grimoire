Storage ownership

APK assets become an internal web directory rebuilt on package update. Library HOME is the external app directory when available, with an internal fallback; persistent port and USB sentinels are device metadata beside the library rather than campaign records. android/app/src/main/java/app/grimoire/ServerRuntime.kt:131, android/app/src/main/java/app/grimoire/ServerRuntime.kt:194, android/app/src/main/python/android_entry.py:52. The Python startup performs a best-effort permission walk and broadens file mode bits for USB access; the assumption is Android app-directory isolation, not POSIX permissions as the privacy boundary. android/app/src/main/python/android_entry.py:26, android/app/src/main/python/android_entry.py:74.

Loopback host is wider than the app origin. WebView navigation accepts localhost or 127.0.0.1 without comparing scheme or the bound port. The comment describes an origin boundary, but the implementation describes a host boundary. No additional origin isolation should be inferred. android/app/src/main/java/app/grimoire/MainActivity.kt:221.

Android network-security XML restricts Java/WebView cleartext to loopback; it explicitly does not govern Python httpx sockets. A LAN provider configured in Python therefore has different transport policy from an external WebView link. android/app/src/main/res/xml/network_security_config.xml:2.

Failure and concurrency

The synchronized runtime publishes one startup result; volatile fields bridge foreground/service state across threads. Port listeners marshal UI changes themselves. Backend-to-Kotlin callbacks and notification/promotion operations log failures and continue, keeping platform UI errors away from backend task groups. android/app/src/main/java/app/grimoire/ServerRuntime.kt:54, android/app/src/main/java/app/grimoire/ServerRuntime.kt:93, android/app/src/main/java/app/grimoire/ServerRuntime.kt:152, android/app/src/main/java/app/grimoire/RunNotifier.kt:126.

Review priorities

1. Do not read “lossless” as active-run durability. The runtime uses that word for process reclaim, but its service exists precisely because reclaim loses in-memory generation. A refused promotion is logged; the adjacent assurance that the reply still reaches disk is conditional on the process remaining alive. android/app/src/main/java/app/grimoire/ServerRuntime.kt:49, android/app/src/main/java/app/grimoire/ServerService.kt:13, android/app/src/main/java/app/grimoire/ServerService.kt:80.
  1. Failed startup is terminal until process restart. started remains latched even after bootstrap publishes failure; another ensureStarted returns immediately. This is an explicit missing transition if adding a Retry action. android/app/src/main/java/app/grimoire/ServerRuntime.kt:85, android/app/src/main/java/app/grimoire/ServerRuntime.kt:176.
  2. SDK upgrades require layout/lifecycle work. targetSdk is held at 34 for edge-to-edge insets, and pure-Python dependency compatibility is separately pinned. Treat build/manifest files as load-bearing despite their omission from source ranking. android/app/build.gradle.kts:22, android/app/build.gradle.kts:71.
  3. Host-only navigation does not isolate the bound server origin. A link to another loopback port stays in the WebView; source alone establishes the mismatch, not an exploit or device test. android/app/src/main/java/app/grimoire/MainActivity.kt:228.
