Judge 1

Theory: Android hosts the same backend and React product inside one app process, using a loopback server and a WebView rather than reimplementing application behavior natively. Native code owns process lifetime, permissions, platform file interactions and notification navigation, while persistent library data remains the backend's responsibility.

Instead of: Instead of introducing a second Android domain model, the APK packages the actual backend sources and frontend bundle; shell callbacks connect run lifetimes to foreground-service and notification behavior.
